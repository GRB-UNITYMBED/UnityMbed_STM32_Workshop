Challenge — แยก Final Project เป็นไฟล์ .c / .h
ทำต่อในโปรเจกต์ Final Project ของคุณที่ Build + Flash ผ่านแล้ว (มาจาก STM32_Lab_Starter จึงมี inc/ และ -Iinc ใน Makefile อยู่แล้ว)
สั่งทีละโมดูล -> Build + Flash ให้ผ่าน -> ค่อยสั่งโมดูลถัดไป

===== 1. จอ OLED + I2C =====
แยกโค้ดจอ OLED และ I2C ออกจาก main.c เป็น src/oled.c, src/i2c.c และ inc/oled.h, inc/i2c.h ให้ main.c include "oled.h" ฟังก์ชันที่ใช้เฉพาะในไฟล์ให้เป็น static ห้ามแก้การทำงาน ตอบทุกไฟล์ครบ ไม่ต้องอธิบาย

===== 2. DHT11 =====
แยกโค้ดอ่าน DHT11 ออกจาก main.c เป็น src/dht11.c และ inc/dht11.h ให้ main.c include "dht11.h" ฟังก์ชันที่ใช้เฉพาะในไฟล์ให้เป็น static ห้ามแก้การทำงาน ตอบทุกไฟล์ที่แก้ครบ ไม่ต้องอธิบาย

===== 3. ปุ่ม =====
แยกโค้ดปุ่ม PA0 และ debounce ออกจาก main.c เป็น src/button.c และ inc/button.h ห้ามแก้การทำงาน ตอบทุกไฟล์ที่แก้ครบ ไม่ต้องอธิบาย

===== 4. Regression =====
แยกโค้ด Linear Regression ออกจาก main.c เป็น src/regression.c และ inc/regression.h ห้ามแก้การทำงาน ตอบทุกไฟล์ที่แก้ครบ ไม่ต้องอธิบาย

===== 5. Anomaly =====
แยกโค้ดเรียนรู้ Mean/SD และตัดสิน ALERT ออกจาก main.c เป็น src/anomaly.c และ inc/anomaly.h ห้ามแก้การทำงาน ตอบทุกไฟล์ที่แก้ครบ ไม่ต้องอธิบาย

--- ถ้าพัง ---
Build ไม่ผ่านเพราะหา .h ไม่เจอ: เช็กว่า Makefile มี -Iinc ใน CFLAGS
Copy Error มาวาง แล้วสั่ง: "ช่วยแก้เฉพาะจุดที่ผิด ห้ามแก้การทำงาน"
ยังไม่หาย: ย้อนไฟล์ของขั้นก่อนหน้า แล้วสั่งแยกโมดูลนั้นใหม่
