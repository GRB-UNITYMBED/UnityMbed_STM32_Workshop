Final Project — Smart Room Monitor
copy โฟลเดอร์ STM32_Lab_Starter เป็นโปรเจกต์ใหม่ แล้ว Open Project ใน IDE แล้วเขียน Prompt เองด้วย C.L.E.A.R.
ทำทีละขั้น: Prompt แรก -> Build + Flash -> Refine ทีละอย่าง -> Build + Flash ทุกครั้ง

===== Prompt แรก (ในสไลด์) =====
[C] โปรเจกต์ใหม่ STM32F103C8T6 Blue Pill bare metal ใช้ clock 8 MHz (HSI) · DHT11 ขา PB12 (จับเวลาบิตด้วย DWT cycle counter ถ้าอ่านได้ 0 ทั้งหมดให้ถือว่า Sensor Error), จอ OLED SSD1306 I2C1 (PB6 SCL, PB7 SDA), ปุ่ม PA0 ลง GND, LED PC13
[L] ขั้นนี้ทำแค่: เปิดเครื่องแสดงหน้า Boot 2 วินาที -> อ่าน DHT11 ทุก 2 วินาที แสดง Temp และ Humi บนจอ
[E] เขียน main.c ครบทั้งไฟล์เป็นโค้ด C ล้วน (ไม่มี ``` และคำอธิบายปนในไฟล์) · บนจอกำกับชื่อทุกค่า · เขียนตัวเลขทับด้วยช่องว่างกันเลขเก่าค้าง · ตารางฟอนต์ใส่เฉพาะตัวที่ใช้ ห้ามใส่ครบทุกตัวอักษร (โค้ดจะยาวจนตอบไม่จบ)
[A] Reset_Handler และ vector table อยู่ใน startup.c แล้ว ห้ามเขียนซ้ำใน main.c · ห้ามใช้ HAL, printf, float · ไม่ต้องส่ง Serial
[R] เริ่มจาก Boot + จอก่อน ขั้นต่อไปจะสั่งเพิ่มทีละอย่าง

===== Refine 1: ค่าทำนาย =====
เพิ่มการทำนายอุณหภูมิถัดไปด้วย Linear Regression จาก 10 ค่าล่าสุด (ใช้จำนวนเต็ม ห้าม float) แสดงบนจอเป็น "Next" · แก้เฉพาะส่วนที่เพิ่ม ส่วนอื่นที่ทำงานได้แล้วห้ามแตะ

===== Refine 2: เรียนรู้ + ALERT =====
เพิ่มช่วงเรียนรู้ความชื้น 15 ค่าแรก (แสดง LEARNING x/15) คำนวณ Mean และ SD (SD ขั้นต่ำ 2) แสดงเป็น H.Mean H.SD · หลังเรียนรู้ ถ้าความชื้นห่างจาก Mean เกิน 3 SD ให้ขึ้น !! ALERT !! และ LED PC13 กะพริบ ไม่งั้นขึ้น NORMAL · แก้เฉพาะส่วนที่เพิ่ม

===== Refine 3: ปุ่มเรียนใหม่ =====
กดปุ่ม PA0 แล้วล้างค่าที่เรียนรู้ เริ่ม LEARNING 0/15 ใหม่ · ห้ามหน่วงเวลานานจนกดปุ่มไม่ติด (ระหว่างรอ 2 วินาทีให้เช็กปุ่มไปด้วย) · แก้เฉพาะส่วนที่เพิ่ม

--- ถ้าพัง ---
AI ตอบไม่จบ: "โค้ดยาวเกินจนตอบไม่จบ เขียน main.c ใหม่ทั้งไฟล์ให้สั้นลง ฟอนต์ใส่เฉพาะตัวที่ใช้ ไม่ต้องอธิบาย"
Copy Error มาวาง แล้วสั่ง: "ช่วยแก้เฉพาะจุดที่ผิด ห้ามแก้ส่วนอื่นที่ทำงานได้แล้ว"
ถ้ายังไม่หาย ย้อนไป main.c ของขั้นก่อนหน้าที่ใช้ได้ แล้วสั่งขั้นนั้นใหม่
